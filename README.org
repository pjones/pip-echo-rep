      import json
      import os.path
      import subprocess

      def download_urls(json_file: str, directory: str):
          with open(json_file) as file:
            urls = json.load(file)

          for link in urls:
              path = os.path.join(directory, link["name"])
              if not os.path.exists(path):
                  print(path)
                  subprocess.run(["curl", "-o", path, link["href"]])

      if __name__ == "__main__":
          download_urls("data/PXD057758/links.json", "data/PXD057758")
    #+end_src

      function download_pride_ftp_url() {
        local url=$1
        local id
        local cache_file

        if [ $# -gt 1 ]; then
          id=$2
        else
          id=$(basename "$url")
        fi

        cache_file="$data_directory/$id/.ls_cache"

        # Ensure there's a slash on the end of the URL:
        if [ "${url: -1:1}" != "/" ]; then
          url="$url/"
        fi

        mkdir --parents "$data_directory/$id"

        # Download and cache the directory listing:
        if [ ! -e "$cache_file" ]; then
          curl --list-only "$url" >"$cache_file"
        fi

        # Make sure each of the files has been downloaded:
        while read -r file; do
          path="$data_directory/$id/$file"

          if [ ! -e "$path" ]; then
            printf "%s\n%s\n" "$url$file" "$path"
            curl --output "$path" "${url}${file}"
          fi
        done <"$cache_file"
      }

      function main() {
        if [ $# -gt 0 ]; then
          data_directory=$1
        fi

        download_pride_ftp_url "ftp://ftp.pride.ebi.ac.uk/pride/data/archive/2019/09/PXD014415/"
        download_pride_ftp_url "ftp://ftp.pride.ebi.ac.uk/pride/data/archive/2018/05/PXD003881/"
        download_pride_ftp_url "ftp://ftp.pride.ebi.ac.uk/pride/data/archive/2018/05/PXD003881/generated/" "PXD003881/generated"
        download_pride_ftp_url "ftp://ftp.pride.ebi.ac.uk/pride/data/archive/2023/07/PXD037527/"

        # Report the size of the directories:
        du \
          --human-readable \
          --summarize \
          --dereference \
          --total \
          "$data_directory"/*
      }

      main "$@"

*** FlashLFQ with PIP-ECHO

    FlashLFQ 2.0.0 was used to quantify the single-cell data.
    Unfortunately the PIP-ECHO supplementary data (PXD057758) did not
    include the identification files necessary and so those files
    needed to be generated with MetaMorpheus.

     However, files ending in =-calib= do not exist in PXD037527 and are
     assumed to have been generated by a MetaMorpheus calibration task.
     No calibration configuration files nor log files were found in the
     supplementary data.  Therefore the default MetaMorpheus
     calibration settings were used.

     Identification in MetaMorpheus was performed using database
     search.  Similar to the calibration step, no configuration file
     was in the supplementary data.  However, the MetaMorpheus log
     provided some of the settings, and the rest of the configuration
     settings were taken from the MetaMorpheus analysis of the
     PXD014415 data set and the default MetaMorpheus settings.  As
     such, the following settings were changed from their default
     values:

     | Setting                          | Default Value | Used Value |
     |----------------------------------+---------------+------------|
     | =DoLabelFreeQuantification=        | true          | false      |
     | =DoLocalizationAnalysis=           | true          | false      |
     | =WriteIndividualFiles=             | true          | false      |
     | =MinAllowedInternalFragmentLength= | 0             | 7          |
     | =QValueThreshold=                  | 0.01          | 1.0        |
     | =PepQValueThreshold=               | 1.0           | 0.01       |

     Note: The last two settings look suspicious and it's not clear why
     they were changed from the default values or if a mistake was
     made.

     Also note that the FASTA file used in this analysis differs from
     the one used in the PIP-ECHO paper.  This analysis used the FASTA
     file that is provided with the RAW data files from PXD037527 and
     not the one used in the PIP-ECHO paper.

     After identification using MetaMorpheus, FlashLFQ can normally be
     run on the =AllPSMs.psmtsv= file produced by MetaMorpheus.  However,
     the column names in the file were changed in a recent MetaMorpheus
     release and FlashLFQ can no longer read these files.  This issue
     was resolved by renaming the columns using a script after
     MetaMorpheus completes but before FlashLFQ starts.

     The following quantification settings were used:

     | Setting                     | Value |

     | =PpmTolerance=                |  10.0 |
     | =IsotopePpmTolerance=         |   5.0 |
     | =NumIsotopesRequired=         |     2 |
     | =MatchBetweenRuns=            |  true |
     | =MbrRtWindow=                 |   1.5 |
     | =MbrDetectionQValueThreshold= |  0.01 |
